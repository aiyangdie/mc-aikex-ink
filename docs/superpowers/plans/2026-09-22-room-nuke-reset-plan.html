00 / GLOBAL CONSTRAINTS

跨任务硬约束

  • 保留原仓库安全/沙箱规则，AGENTS.md 的用户注入差异不得提交。

  • 仅在本地服务/临时房间测试；不得对生产联机房间触发核弹或地形重置。

  • 口令完全匹配 Maydaymayday；半径 12；每房间 5 分钟冷却且重启保留。
  • 只有房主可以重置地形；二次确认，清地形不清背包/Boss 倒计时。

02 / REVIEW FOCUS

最容易遗漏的输入与异常

  1. 输入含 HTML/超长/高频聊天：按文字显示且服务端限制，不执行脚本。
  2. 同时两人输入口令：同房间只成功一次，其他房间不受影响。
  3. 房主掉线/重连/改名：重置权限不可由名字冒充。
  4. 核爆在地狱或末地：弹坑不能错误写入主世界旧 edits。
  5. 核爆后刚好重置/重连：旧 block 增量不得覆盖新的快照。

    export function craterCells(o,r=12,height=48) {
 const cells=[];
 for(let x=Math.floor(o.x-r);x<=o.x+r;x++)
 for(let z=Math.floor(o.z-r);z<=o.z+r;z++)
 for(let y=Math.max(0,Math.floor(o.y-r/2));y<Math.min(height,Math.ceil(o.y+r/2));y++)
   if((x-o.x)**2+(z-o.z)**2+((y-o.y)*1.3)**2<=r*r)cells.push([x,y,z,0]);
 return cells;
}
