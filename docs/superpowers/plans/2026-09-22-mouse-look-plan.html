For agentic workers: 执行前由用户选择单会话或子代理方式；逐任务 TDD 红绿、验证并提交，未验证不得声称完成。

Goal: 桌面端无需按住右键即可移动视角，右键只放置；聊天/确认框期间视角暂停。

Architecture: 保留 Pointer Lock 主路径，替换现有 fallback 的右键拖动为画布 hover mousemove；控制状态由 Game._controlsActive 与 _chatOpen 统一门控。

Tech Stack: DOM Pointer Lock API、Three.js、node:test、Playwright

02 / REVIEW FOCUS

最容易遗漏的输入与异常

  1. Pointer Lock 被拒绝：无按键鼠标移动仍转视角。
  2. 移动到聊天输入框/确认按钮：视角不得改变。
  3. 右键点击画布：只放置一次，不再启动拖动；contextmenu 不弹出。
  4. 浏览器失焦：按键清空并暂停，回焦不自动移动。
  5. 正常 Pointer Lock 下从游戏切到聊天再返回：不产生突跳。

    _canMouseLook(target) {
 return this._controlsActive() && !this._chatOpen && target===this.canvas;
}
_handleMouseMove(e) {
 if(!this._canMouseLook(e.target))return;
 if(this.isPointerLocked)this.player.onMouseMove(e.movementX,e.movementY);
 else if(this._fallbackActive){const last=this._lastMousePoint;
  if(last)this.player.onMouseMove(e.clientX-last.x,e.clientY-last.y);
  this._lastMousePoint={x:e.clientX,y:e.clientY};}
}
_handleMouseDown(e){if(!this._controlsActive()||this._chatOpen)return;
 if(e.button===2)this._secondaryAction();else if(e.button===0)this._primaryAction();}
