Boss 60 秒再刷新 · 实现计划

For agentic workers: 执行前由用户选择单会话或子代理方式；逐任务 TDD 红绿、验证并提交，未验证不得声称完成。

Goal: 联机和单机 Boss 每次死亡后 60 秒再出现，满血 1500，刷新计时可跨重连/重启。

Architecture: RoomBoss 使用 wall-clock respawnAt；Game 单机存档同样记录。所有击杀路径统一调用 kill(now)，避免核弹/AK/近战计时不一致。

Tech Stack: Node.js ESM/CommonJS bridge、Three.js、node:test

Spec: docs/superpowers/specs/2026-09-22-room-nuke-reset-design.html

02 / REVIEW FOCUS

最容易遗漏的输入与异常

  1. 死亡发生在 59.9 秒与 60 秒边界：不能早刷。
  2. 同一帧两个伤害来源同时致死：只能设一次倒计时。
  3. 服务端重启后加载死亡 Boss：应继承原 respawnAt。
  4. 客户端未加载完成时服务器发新 Boss：不得出现两个模型。
  5. 单机读档时倒计时已过：进入世界即可满血刷新。
